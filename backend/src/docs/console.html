TrustFeed API Console

TrustFeed is a secure, production-style social REST API demonstrating clean architecture, JWT authentication with HTTP-only cookies, RBAC + ABAC authorization, cursor-paginated feeds, and asynchronous notifications. This console lets you browse the full API contract and execute real requests against a running backend.

  • Authenticate with your real TrustFeed session — cookies are sent automatically.
  • Explore endpoints grouped by domain: Auth, Posts, Comments, Follows, Likes, Feed, Notifications, Admin, Health.
  • Test advanced behaviors: idempotency, optimistic concurrency, pagination, and rate limiting.
